## Michell Zappa

Native software for Apple platforms, small web tools, and firmware for microcontrollers. Most of it is local-first, and most of it is here.

### AI and developer tooling

| | |
|---|---|
| [headroom](https://github.com/michellzappa/headroom) | Local-first AI coding quotas and ship status, on your menu bar, iPhone, Watch and an ESP32 desk display. |
| [helm](https://github.com/michellzappa/helm) | Observability dashboard for OpenClaw. Reads your local workspace directly: sessions, spend, crons, agents. |
| [core-oss](https://github.com/michellzappa/core-oss) | Minimalist open-source CRM built with Next.js, Supabase and Tailwind. Designed to be extended with Claude Code. |

### Apple platforms

| | |
|---|---|
| [septena](https://github.com/michellzappa/septena) | A private, local-first life OS. One app for everything you track. [septena.app](https://www.septena.app) |
| [cartogram](https://github.com/michellzappa/cartogram) | Map wallpapers generated from your photo locations. All on-device. |
| [tessellate](https://github.com/michellzappa/tessellate) | Menu-bar window manager. Hotkey, command key, window moved. |
| [cargo](https://github.com/michellzappa/cargo) | Menu-bar app that brings finished Put.io downloads home to a local SSD library for Infuse. |
| [clip](https://github.com/michellzappa/clip) | Menu-bar clipboard history. ⇧⌘V, type to filter, ⏎ pastes. Text only. |
| [lift](https://github.com/michellzappa/lift) | Menu-bar controller for Linak standing desks (IKEA Idasen). Hotkey, desk moves. |
| [housekit](https://github.com/michellzappa/housekit) | Shared SPM package behind Tessellate, Cargo, Clip and Lift: glyphs, icon plates, settings windows, hotkeys, launch at login. |
| [athanor](https://github.com/michellzappa/athanor) | Generative sacred geometry screen saver, with tvOS and iPhone companions. |
| [easysubs](https://github.com/michellzappa/easysubs) | Drop a video. Get its subtitles. |

| | |

### TinySuite

Small native macOS editors and viewers. One file type each, no dependencies, built on [tinykit](https://github.com/michellzappa/tinykit).

| | |
|---|---|
| [tinytext](https://github.com/michellzappa/tinytext) | Plain text |
| [tinymark](https://github.com/michellzappa/tinymark) | Markdown |
| [tinyjson](https://github.com/michellzappa/tinyjson) | JSON |
| [tinyyaml](https://github.com/michellzappa/tinyyaml) | YAML |
| [tinycsv](https://github.com/michellzappa/tinycsv) | CSV |
| [tinylog](https://github.com/michellzappa/tinylog) | Log files, with live tail |
| [tinypdf](https://github.com/michellzappa/tinypdf) | PDF text extraction, with OCR |
| [tinysql](https://github.com/michellzappa/tinysql) | PostgreSQL tables, read-only |
| [tinytask](https://github.com/michellzappa/tinytask) | Tasks |
